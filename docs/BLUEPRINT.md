## 0. ICE 제품군 정합성 (기존 코드 분석 결과)

ICEFiction은 **ICEPDF·ICEWriter·ICEThreads의 4번째 형제**다. 이미 검증된 스택·디자인·AI 패턴을
그대로 계승해 "처음부터 ICE답게" 만든다. 아래는 기존 코드에서 확인한 사실이다.

### 0.1 확정된 하우스 스택 (ICEPDF에서 그대로 검증됨)

ICEPDF가 이미 **내가 §3에서 제안한 것과 동일한 스택**으로 배포 중이다. 새로 정할 게 아니라 **복제**한다.

| 항목 | ICEPDF 실제 사용 (계승) |
|---|---|
| 셸 | **Electron 42** + **electron-vite 5** + **electron-builder 26** |
| UI | **React 19** + **zustand 5** + **TypeScript 5.9** |
| 스타일 | **손으로 쓴 `global.css`** (시맨틱 클래스, 한글 주석) — ⚠️ **Tailwind·Radix 안 씀** |
| 구조 | `src/main` · `src/preload` · `src/renderer` · `src/shared/types.ts` |
| 무거운 작업 | `worker_thread` 분리 (mupdf 엔진, kordoc 변환) |
| 테스트 | `tsx` 단위 + `node` 스모크(e2e) |
| 배포 | Win: electron-builder NSIS / Mac: DMG |
| 문서 | `사양서.txt` + `docs/ARCHITECTURE.md` + `docs/DEVLOG.md` |
| 라이선스/후원 | author `icenovel`, ☕ Buy Me a Coffee(앱 내 QR 모달) |

→ **§3의 Tailwind + Radix 제안은 철회**. 제품군 일관성·의존성 최소화를 위해 손으로 쓴 CSS를 따른다.
   (에디터가 복잡해도 ICEPDF의 뷰어/툴바/모달이 순수 CSS로 충분히 정교하게 구현돼 있음을 확인.)

### 0.2 AI 추상화는 ICEWriter에서 이식 (재발명 금지)

ICEWriter `icewriter/core/ai/`에 **정확히 내가 §7에서 설계한 3계열 어댑터가 이미 존재**한다.
Python이지만 계약이 명확해 TypeScript로 1:1 포팅하면 된다. 자세한 계승 내용은 §7 참조.

- `base.py` → `TextAI` ABC (`generate` / `check_connection` / `cancel`), `AIErrorKind` enum, `classify_error`
- `api_text.py` → API 어댑터 / `cli_text.py` → CLI 어댑터(`claude -p`, `codex exec`) / `factory.py` → 선택
- **핵심 정책**: `PAUSE_KINDS`(auth 만료·rate limit·quota 소진) = "멈추고 나중에 이어서"

### 0.3 아이콘·색상 정체성

세 아이콘 모두 **같은 8각 얼음결정 눈꽃**(청록/시안 패싯 그라디언트)을 공유하고,
**우하단 원형 배지의 글자+색**으로만 앱을 구분한다:

| 앱 | 배지 글자 | 배지 색(브랜드 액센트) |
|---|---|---|
| ICEPDF | P | 청록 `#3a9ca8` 계열 |
| ICEWriter | W | 주황 `#f39019` 계열 |
| **ICEFiction** | **F** | **남색/인디고 `#2e2b8f` 계열** ← 제공된 아이콘 |

→ **ICEFiction UI 액센트 색 = 남색/인디고**(`#312d99` 근처). ICEPDF의 파랑(`#1f6feb`)과 구별되는
   ICEFiction만의 정체색. 다크 IDE 톤은 공유하되 강조색만 이 남색으로 바꾼다. (디자인 토큰은 §8.1)

## 1. 비전과 목표

**한 줄 정의**: "작가의 원고·설정·AI 조수를 한 화면에 모은, 로컬 파일 기반 집필 도구."

핵심 가치 3가지:

1. **내 데이터는 내 파일** — 프로젝트는 평범한 마크다운 폴더. 전용 DB에 가두지 않는다.
   클라우드 동기화(Naver MYBOX, Dropbox 등)에 그냥 올려도 되고, 프로그램이 죽어도 원고는 산다.
2. **AI는 조수, 작가가 주인** — AI 출력이 원고를 직접 덮어쓰지 않는다. 항상 제안 → 검토 → 적용,
   적용 전 자동 스냅샷으로 언제든 되돌린다.
3. **집필 흐름 우선** — 설정 관리 도구가 아니라 "쓰는 도구". 에디터 경험(한글 입력, 폰트, 집중 모드)이 1순위.

### 비목표 (v1에서 안 하는 것)

- 실시간 공동 집필 / 클라우드 계정 / 서버
- 모바일 앱
- 플러그인 시스템 (v2 후보)
- 출판 조판(InDesign 수준) — 내보내기는 "투고·연재용으로 충분한" 수준까지만

## 2. 타깃 사용자와 시나리오

- **주 사용자**: 장편(웹소설/일반 소설) 작가. 챕터 수십~수백 개, 캐릭터 수십 명 규모.
- 핵심 시나리오:
  - S1. 오늘 쓸 챕터를 열고, 어제 쓴 부분 이어서 집필. 글자수 목표 확인.
  - S2. 집필 중 "이 캐릭터 눈 색이 뭐였지?" → 사이드에서 캐릭터 시트 즉시 확인.
  - S3. AI에게 "이 장면 계속 써줘 / 이 문단 퇴고해줘" — 현재 씬 + 등장 캐릭터 시트가 자동으로 컨텍스트에 포함.
  - S4. 완성된 1~30화를 TXT(연재 플랫폼용)나 DOCX(투고용)로 내보내기.
  - S5. AI에게 "설정 모순 검사해줘" → 세계관 문서 대조 리포트.

## 3. 기술 스택 (제안)

### 3.1 프레임워크: **Electron** (추천) vs Tauri

| | Electron (추천) | Tauri 2 |
|---|---|---|
| 언어 | TS 하나로 전체 개발 | 프론트 TS + 백엔드 Rust |
| CLI LLM 연동 (`claude -p` 등) | `child_process` 스트리밍 — 매우 쉬움 | Rust Command + 이벤트 브리지 — 가능하지만 번거로움 |
| 생태계/선례 | Obsidian, VS Code, Notion — 검증됨 | 성장 중 |
| 배포 크기/메모리 | ~100MB+, 무거움 | ~10MB, 가벼움 |
| Win→Mac 이식 | 우수 (동일 코드) | 우수 (동일 코드) |

**추천 근거**: 이 앱의 차별점이 AI 연동인데, `-p` CLI 호출·스트리밍 파싱·프로세스 관리가
Node에서 압도적으로 간단하다. 1인 개발 속도 우선. 바이너리 크기가 중요해지면 그때 Tauri 검토.

### 3.2 확정 스택 (ICEPDF 하우스 스택 계승 — §0.1)

- **셸/빌드**: Electron 42 + electron-vite 5 + electron-builder 26 (Win NSIS, Mac DMG) + electron-updater(자동 업데이트)
- **UI**: React 19 + TypeScript 5.9 + **zustand 5** (상태) + **손으로 쓴 `global.css`** (Tailwind·Radix 없음 — §0.1)
- **에디터**: CodeMirror 6 — 마크다운 라이브 프리뷰(Obsidian 방식).
  한글 IME 조합 입력 처리가 검증된 몇 안 되는 웹 에디터 엔진. (ICE 제품군 중 첫 본문 에디터 도입 — §11 최대 리스크)
- **검색·인덱스**: ~~better-sqlite3 + FTS5~~ → **메인 프로세스 실시간 스캔**으로 변경(2026-07-17,
  결정 D1). FTS5 기본 토크나이저는 한국어 부분일치가 안 되고(trigram 별도 처리 필요), 네이티브
  모듈은 Win/mac Electron 리빌드 부담이며, 책 한 권 규모는 매 검색 스캔으로 충분히 빠르다.
  "진실은 항상 .md" 원칙에도 부합. FTS5는 링크 그래프·통계가 필요해지는 시점에 재론.
- **파일 감시**: chokidar (외부 편집·클라우드 동기화 반영)
- **무거운 작업**: `worker_thread` 분리 (인덱싱, 내보내기 컴파일 — ICEPDF의 engine/convert worker 패턴 계승)
- **내보내기 엔진**: `kordoc`(자체 라이브러리, MD↔HWPX — ICEPDF에서 사용 중) + `docx` + `epub-gen`
- **시크릿**: Electron `safeStorage` (Win Credential Manager / macOS Keychain 백엔드) — API 키는 절대 프로젝트 폴더에 저장 안 함
- **테스트**: `tsx` 단위 + `node` 스모크(e2e) — ICEPDF 관례. (Playwright는 electron-builder devDep에 이미 존재하나 ICEPDF는 node 스모크 위주)

## 4. 데이터 모델: "마크다운 폴더 = 프로젝트"

전용 포맷 대신 **폴더 규약**. 서랍장에 라벨 붙여 정리하는 것과 같다 — 서랍장이 없어져도 서류는 그대로 읽힌다.

```
내소설/                        ← 이 폴더가 곧 프로젝트 (통째로 복사=이동, §6.11)
├─ icefiction.json             ← 프로젝트 매니페스트 (제목, 구조 순서, schemaVersion)
├─ manuscript/                 ← 원고 (부 > 챕터 > 씬 트리)
│  ├─ 1부-시작/
│  │  ├─ 01-폭우.md
│  │  └─ 02-재회.md
├─ characters/                 ← 캐릭터 시트
│  └─ 김철수.md
├─ world/                      ← 세계관
│  ├─ locations/  factions/  rules/  glossary.md  timeline.md
├─ notes/                      ← 자유 노트, 자료조사
├─ assets/                     ← 자료(이미지·동영상·PDF·오디오·참고문서) — §6.10
│  ├─ images/  video/  refs/   (드래그드롭·붙여넣기로 여기 복사)
│  └─ .thumbs/                 ← 썸네일 캐시(자동 생성, 동기화 제외)
├─ trash/                      ← 휴지통 (삭제 = 이동)
├─ snapshots/                  ← 문서별 버전 스냅샷
└─ .ice/                       ← 캐시·인덱스·AI 대화기록·기기별 설정 (동기화 제외 가능)
```

**폴더 안 경로 규약(이식성의 핵심 — §6.11)**: 문서·프론트매터가 자료를 가리킬 때는 **항상 프로젝트
루트 기준 상대경로(POSIX `/`)**로만 적는다 (`assets/images/철수-얼굴.jpg`). 절대경로·`\`·기기 종속
경로 금지. 이래야 폴더를 다른 컴퓨터로 옮겨도 모든 링크가 그대로 산다.

### 문서 = 마크다운 + YAML 프론트매터

```markdown
---
type: chapter
title: 폭우
status: draft          # draft | revising | done
pov: 김철수
synopsis: 철수가 빗속에서 옛 친구를 만난다.
order: 1
words_target: 5000
---

# 폭우

비가 쏟아지기 시작한 것은...
```

캐릭터/세계관도 동일 구조 (`type: character`, `type: location` 등 + 커스텀 필드).

**설계 원칙**:
- 진실의 원천(source of truth)은 항상 .md 파일. SQLite는 검색·통계용 파생 인덱스.
- 저장은 원자적 쓰기(temp 파일 → rename) — 클라우드 동기화 폴더에서의 충돌·유실 방지.
- 외부 에디터(Obsidian, VS Code)로 열어 편집해도 깨지지 않는다. chokidar가 감지해 반영.

## 5. 아키텍처

```
┌─ Renderer (React) ─────────────────────────────────────────┐
│  바인더 │ 에디터(CM6) │ 인스펙터·자료 │ AI 패널 │ 라이트박스 │ 내보내기 │
└──────────────────── typed IPC ─────────────────────────────┘
┌─ Main Process (Node) ──────────────────────────────────────┐
│  ProjectService   파일 CRUD, 프론트매터 파싱, 원자적 저장          │
│  IndexService     SQLite FTS, 글자수 통계, 링크 그래프           │
│  AssetService     자료 반입(복사/링크), 썸네일(worker), 코덱 판정   │  ← §6.10
│  PortabilityService  .icefic 번들 입출력, 경로 검증, 누락 감지      │  ← §6.11
│  SnapshotService  버전 스냅샷, diff                            │
│  AIService        프로바이더 추상화 (§7)                        │
│  ExportService    TXT/MD/DOCX/EPUB 컴파일                     │
│  SecretService    safeStorage 래핑                            │
└────────────────────────────────────────────────────────────┘
```

- 렌더러는 파일시스템 직접 접근 금지(contextIsolation) — 모든 IO는 Main 경유. 보안 + Mac 이식성 확보.
- 대용량 미디어는 `file://` 직접 로드 대신 **커스텀 프로토콜(`ice-asset://`)**로 서빙 — contextIsolation
  유지하면서 이미지·동영상을 안전·효율적으로 표시(경로 노출·CSP 문제 회피).
- IPC는 타입 공유(zod 스키마로 양방향 검증).

## 6. 기능 명세

### 6.1 에디터 (최우선 품질)

- 마크다운 라이브 프리뷰 (기호는 커서 근처만 노출, 나머지는 렌더링 — Obsidian 방식)
- 한글 집필 필수 요소: **글자수(공백 포함/제외) + 원고지 매수** 실시간 표시, 세션 글자수
- 집중 모드(문단 하이라이트 + 주변 흐리기), 타자기 스크롤(현재 줄 고정), 전체화면
- 폰트·줄간격·본문 폭 커스터마이즈 (집필용 명조 계열 기본)
- 자동 저장(디바운스 2초) + 크래시 복구
- 씬 구분자(`---`), 챕터 분할/병합
- `[[위키링크]]`: 캐릭터·세계관 문서 자동완성, 호버 미리보기, 백링크 패널

### 6.1a 고스트 텍스트 — AI 제안은 '유령'이다 *(구현: `lib/ghostText.ts`)*

AI 제안은 문서에 들어가지 않은 채 커서 뒤에 **흐린 글씨**로만 뜬다(위젯 데코레이션 1개).
연필로 밑그림을 그려 두고 마음에 들 때만 펜으로 덧그리는 것과 같다.

- `Tab` 채택 → 그때 비로소 진짜 글자가 된다 · `Esc` 버리기(생성 중이면 함께 중지)
- 사용자가 글자를 치면 제안은 자동으로 사라진다(엉뚱한 자리에 남지 않게)
- 제안이 없을 때 `Tab`/`Esc`는 **기존 동작으로 그대로 넘어간다**(전각 들여쓰기·선택 해제)
- 갈아끼우는 명령(`/다듬기`)은 대상 범위를 함께 들고 있다가 `Tab`에서 통째로 교체한다

**약속은 눈에 보여야 지켜진다** — 규칙을 아는 사람만 쓸 수 있으면 없는 기능이다. 같은 말을 세 겹으로 적는다.

1. **꼬리표**: 흐린 글씨 끝에 `/이어쓰기 · Tab 확정 · Esc 취소`(생성 중이면 `쓰는 중… Esc 중지`).
   위젯 안에 그리므로 원고에는 한 글자도 안 남는다(E2E가 `.cm-ghost`를 걷어내고 검증).
2. **안내 막대**: 본문 아래 가운데에 같은 말 + **누를 수 있는** `Tab 확정` / `Esc 취소` 단추
   (마우스로 쓰는 사람도 있다). 제안이 사라지면 막대도 사라진다.
3. **미리 예고**: 슬래시 메뉴가 고르기 **전에** 꼬리표(`Tab 확정`)와 발치 안내로 알려 준다.

실패·저장은 말로 알린다 — 슬래시 명령이 실패하거나(`inlineNotice`) `/줄거리`가 문서 정보로 갔을 때,
AI 패널이 닫혀 있어도 본문 아래에 한마디가 잠깐 뜬다(6초 후 자동 소멸).

### 6.1b 슬래시 명령 — 본문에서 부르는 AI *(구현: `shared/slashCommands.ts`, `lib/slashMenu.ts`)*

본문에서 `/`를 치면 그 자리에 AI 명령 목록이 뜬다. 패널로 시선을 옮기지 않는 것이 요점이다.

| 아이콘 | 명령 | 하는 일 | 꼬리표(결과가 가는 곳) |
|---|---|---|---|
| ✍ | `/이어쓰기` | 커서 직전 흐름을 이어 2~4문단 | `Tab 확정` |
| ✨ | `/다듬기` | 커서가 놓인 문단을 윤문 | `Tab 확정`(그 문단을 교체) |
| 🌿 | `/묘사` | 감각 묘사 1~2문단 보강 | `Tab 확정` |
| 💬 | `/대사` | 상황에 맞는 대사 제안 | `Tab 확정` |
| 📌 | `/줄거리` | 이 장면의 한 줄 줄거리 | `문서 정보로`(프론트매터 `synopsis`) |
| 🎨 | `/삽화` | 이 자리에 넣을 그림 생성(§7.6) | `그림 창 열기` → `![](상대경로)` |

- 줄 첫머리·공백 뒤의 `/`에서만 뜬다(`assets/…` 같은 경로 한가운데서 튀어나오지 않게)
- 맥락(문체·원고·자료)은 채팅과 똑같이 싣되, **결과는 채팅에 쌓지 않는다**
- 목록 생김새: `[아이콘] [이름] [설명] [꼬리표]` + 머리말 `AI 명령 — 커서 자리에서 실행` +
  발치 `↑↓ 고르기 · Enter/Tab 실행 · Esc 닫기 — 결과는 흐린 글씨로 먼저…`
- 자동완성 기본 정렬은 가나다순이라 `boost`로 카탈로그 순서를 되살린다(`/`만 쳐도 `/이어쓰기`가 위)
- 메뉴가 떠 있으면 `Tab`도 실행(고스트 `Tab` → 자동완성 `Tab` → 전각 들여쓰기 순으로 양보)

### 6.7 내보내기 (Compile) — *원고를 배포 포맷으로*

### 6.10 자료(Assets) — 넣기 쉽게, 보기 좋게

자료를 "쉽게 넣고 잘 보는" 것을 1급 기능으로 둔다. 폴더가 곧 프로젝트라는 강점을 최대한 살린다.

**넣기(Ingest) — 마찰 0을 목표로**
- **드래그드롭**: OS 탐색기/파인더에서 이미지·동영상·PDF·오디오를 앱 어디로든 끌어놓으면
  `assets/`의 종류별 폴더로 **복사**(원본 이동 아님) 후 자동 인덱싱. 드롭 위치가 문서 위면 그 문서에 첨부.
- **붙여넣기**: 클립보드 이미지(캡처·웹 이미지) `Ctrl+V` → `assets/images/`에 저장 + 커서에 `![[파일]]` 삽입.
- **URL 드롭/붙여넣기**: 이미지 URL은 내려받아 저장(선택), 일반 URL은 참고 링크 노트로 저장.
- **빠른 담기(Quick Capture)**: 전역 단축키로 클립보드 내용을 현재 프로젝트 `notes/`·`assets/`에 즉시 투척.
- **폴더 열기 버튼**: "프로젝트 폴더 열기"(탐색기/파인더), 문서/자료 우클릭 → "탐색기에서 보기"
  (ICEPDF에 없는, 폴더-네이티브 앱만의 편의). 그대로 탐색기에서 대량 복사해 넣어도 chokidar가 감지.

**보기(View) — 집필하며 곁눈질**
- **인스펙터 미디어 탭 / 자료 패널**: 현재 문서(캐릭터·씬)에 첨부된 이미지·동영상 썸네일 그리드.
  캐릭터 시트엔 얼굴 레퍼런스, 씬엔 분위기 이미지·지도.
- **라이트박스**: 썸네일 클릭 → 확대 뷰(줌·패닝·좌우 이동 — ICEPDF 뷰어 상호작용 계승).
- **동영상 재생**: Electron/Chromium `<video>`로 인앱 재생(참고 영상: 안무·액션·풍경 등).
  ⚠️ **코덱 한계** — Chromium은 H.264/VP9/AV1(mp4·webm)만 확실. HEVC·일부 MKV는 재생 불가 →
  그런 파일은 "시스템 기본 플레이어로 열기"로 폴백(shell.openPath).
- **에디터 인라인 프리뷰**: 본문/시트의 `![[image]]`를 CM6에서 인라인 렌더(Obsidian식). 호버로 확대.
- **무드보드(v2)**: 자료를 자유 배치하는 캔버스 보드 — v1은 그리드 갤러리로 시작.
- **썸네일**: `assets/.thumbs/`에 캐시(worker_thread 생성), 대용량 폴더도 지연 로드로 가볍게.

**용량·동기화 배려(중요)** — 동영상·고해상 이미지는 크다. 클라우드 동기화 폴더(MYBOX 등)에서 문제될 수 있어:
- 자료를 **프로젝트 안에 복사(기본, 이식성 우선)** vs **외부 원본 링크(용량 절약, 이식성 희생)** 선택.
  기본은 복사(옮겨도 안 깨짐). 대용량은 링크를 권하되 §6.11의 "누락 자료 감지"로 안전망.
- `.thumbs/`·`.ice/`는 동기화 제외 후보(`.gitignore`류 규약 + 안내).

### 6.11 이식성 — 다른 컴퓨터로 불러오기·내보내기

폴더 기반이라 "**폴더 통째 복사 = 이동**"이 기본이지만, 깨지는 지점을 막고 두 갈래 경로를 제공한다.

**두 가지 이동 경로**
1. **클라우드 동기화**(MYBOX·Dropbox 등): 프로젝트 폴더를 동기화 폴더에 두면 여러 컴퓨터가 자동 공유
   (지금 이 폴더처럼). 별도 작업 0. — 원자적 쓰기(§4)·`.ice/` 동기화 제외로 충돌 최소화.
2. **프로젝트 번들** `.icefic` (= 폴더 zip): "내보내기"로 단일 파일 생성 → USB·메일·백업.
   "불러오기"로 어느 컴퓨터에서든 펼침. 동기화를 안 쓰거나 남에게 통째로 넘길 때.

**이식성을 지키는 규칙(설계에 못박기)**
- **모든 내부 참조는 상대·POSIX 경로**(§4) — 절대경로 0. 기기가 바뀌어도 링크 무손상.
- **기기 종속 항목은 폴더 밖으로 분리**: API 키(OS 자격증명 저장소), 창 크기·기기 성능 설정은 `.ice/`
  또는 앱 전역 설정에. → 폴더에는 "이 프로젝트의 것"만 남아 어디서 열든 동일.
- **설정 이원화**: *프로젝트 설정*(구조·집필 목표·테마 — 폴더에 저장, 이동 시 따라옴) vs
  *기기 설정*(어떤 LLM·경로 — 컴퓨터별). 프로젝트가 선호 LLM을 힌트로 남기되, 그 기기에 없으면 조용히 폴백.
- **`schemaVersion`** — 매니페스트에 버전. 다른(구/신) 버전 앱이 열면 마이그레이션 or 안전 안내.
- **폰트 이식**: 집필 테마가 특정 폰트를 쓰면 다른 컴퓨터엔 없을 수 있음 → OFL 폰트 번들(ICEWriter 선례)
  + 폴백 선언.
- **누락 자료 감지**: 다른 컴퓨터에서 열 때 (외부 링크 자료가 안 따라왔거나 경로 깨지면) **깨진 링크
  리포트** → 다시 연결·무시 선택. 참조 안 되는 고아 자료 정리 도구도 함께.

**불러오기(기존 원고 반입)** — "불러오기"의 또 다른 의미. 새 프로젝트를 빈손으로 시작 안 하게:
- 기존 `.txt`/`.docx`/`.md`/마크다운 폴더를 챕터로 임포트(문단·구분자 기준 분할 옵션).
- (v2) 스크리브너 등 타 도구 폴더 임포트 검토.

## 7. AI 어시스턴트 상세 설계

> **핵심 결정: 재발명하지 않고 ICEWriter `core/ai/`를 TypeScript로 이식한다.** 아래 설계는 이미
> ICEWriter에서 프로덕션 검증된 계약이다. 계약(인터페이스·에러 정책·CLI 노하우)을 1:1로 옮기고,
> ICEFiction은 여기에 "제안이 아니라 소설 집필용 상호작용"(§7.3)만 새로 얹는다.

### 7.1 프로바이더 추상화 — 3계열 어댑터 (ICEWriter `base.py` 이식)

```ts
type AIErrorKind =
  | 'auth_expired' | 'rate_limited' | 'quota_exhausted'   // = PAUSE_KINDS (멈추고 이어서)
  | 'not_installed' | 'network' | 'cancelled' | 'other'

interface TextAI {
  name: string
  agentic: boolean            // CLI 에이전트(파일 도구 보유) 여부
  lastSessionId?: string      // claude --resume 용 (generate 후 채워짐)
  generate(prompt: string, opts: {
    system?: string; cwd?: string; timeoutMs?: number;
    env?: Record<string,string>; resume?: string
    onLog?: (line: string) => void; signal: AbortSignal
  }): Promise<string>
  checkConnection(): Promise<ConnStatus>   // 가벼운 실호출 1회로 로그인/키/한도 점검
  cancel(): void
}
```

| 어댑터 | 커버 범위 | 구현 (ICEWriter 대응) |
|---|---|---|
| **Anthropic API** | Claude 계열 | 공식 SDK, 스트리밍 (`api_text.py`) |
| **OpenAI 호환 API** | OpenAI, **Ollama, LM Studio**, OpenRouter, Groq 등 base URL만 바꾸면 전부 | fetch + SSE (`api_text.py` 확장) |
| **CLI** | `claude -p`(stream-json), `codex exec`, `gemini -p` | child_process + stdout 파싱 (`cli_text.py`) |

- 로컬 LLM은 별도 어댑터가 아니라 OpenAI 호환 어댑터의 base URL 변경으로 흡수 (Ollama/LM Studio 모두 지원).
- **에러 분류(`classify_error`)**: CLI/API 출력에서 정규식으로 종류 추정 → `PAUSE_KINDS`면 조용히 정지하고
  "재로그인/충전 후 이어쓰기" 안내. ICEWriter의 한/영 이중 정규식 패턴을 그대로 이식.
- 프로바이더별 토큰 사용량·추정 비용 누적 표시.

### 7.1a CLI 어댑터 이식 시 반드시 지킬 노하우 (ICEWriter `cli_text.py`에서 실측·검증)

이건 재발견하면 며칠씩 날리는 함정들이다. Node 이식 시 그대로 옮긴다:

1. **프롬프트는 argv가 아니라 stdin으로** — Windows 명령줄 8191자 제한 + cmd.exe 특수문자 해석 회피.
   (집필 프롬프트는 길고 마크다운을 담음)
2. **stdin 쓰기 / stdout 읽기를 분리** — Node는 스트림이 비동기라 유리하나, 큰 프롬프트를 다 쓰기 전
   자식이 stdout을 채우면 파이프 데드락. `stdin.end()`를 별도로, stdout은 `readline`으로 소비.
3. **유휴 타임아웃(5분 무출력=행) + 하드 타임아웃** 이중 — 자식이 출력 없이 멈추면 하드 타임아웃에
   도달조차 못 한다. "출력=살아있음"으로 유휴 타이머 리셋.
4. **`cwd`는 임시폴더 기본값** — `cwd=undefined`면 자식(codex→node_repl 등)이 설치 폴더를 상속·잠가
   업그레이드 시 "파일 사용 중"으로 실패. 반드시 `os.tmpdir()`를 기본 cwd로.
5. **프로세스 트리 종료** — 중단 시 Windows `taskkill /F /T /PID`, macOS `SIGTERM`. 자식까지 다 죽여야 함.
6. **Windows 콘솔창 숨김** — spawn 시 `windowsHide: true` (Python의 `CREATE_NO_WINDOW` 대응).
7. **npm 심(`.cmd`/`.bat`) 래핑** — Windows에서 `claude.cmd` 등은 `cmd /c`로 감싸 실행.
8. **PATH 보강** — macOS는 Finder/launchd 실행 시 최소 PATH만 줘서 `~/.npm-global/bin`,
   `/opt/homebrew/bin` 등의 CLI를 못 찾아 "설치 안 됨" 오판. 로그인 셸 PATH 병합 + 알려진 위치 폴백.
9. **`claude -p`**: `--output-format stream-json --verbose`로 받아 진행(작성 텍스트·도구 사용)을
   실시간 로그로 흘리고 `result` 텍스트만 반환. `session_id` 캡처 → `--resume`로 연속 대화.
10. **`codex exec`**: `--skip-git-repo-check` 필수(소설 폴더는 git 아님 → 즉시 거부),
    `--output-last-message <file>`로 최종 답변만(stdout은 프롬프트 에코가 섞임), `approval_policy=never`.

### 7.2 컨텍스트 빌더 (핵심 차별점)

AI에게 뭘 보여줄지는 작가가 통제하되, 프로그램이 똑똑하게 제안:

- **자동 제안**: 현재 씬 텍스트에서 캐릭터·용어 이름을 감지 → 해당 시트를 컨텍스트 후보로 자동 추가
- **컨텍스트 칩 UI**: AI 패널 상단에 `[현재 씬] [김철수.md] [세계관/마법체계.md] [+추가]` — 클릭으로 켜고 끄기
- **토큰 예산 게이지**: 포함된 문서의 합산 토큰 표시, 초과 시 경고·자동 요약 제안
- 시놉시스 체인: 이전 챕터들은 본문 대신 시놉시스만 넣어 장편에서도 맥락 유지

### 7.2a 문체 방(`style/`) — 항상 이 문체로 (하네스) *(구현: `project.ts buildStyleBlock`)*

옷을 맞출 때 매번 치수를 새로 재지 않고 **본을 떠 두는** 것과 같다. 문체 방이 그 본이고,
모든 AI 요청은 그 본 위에서 재단된다.

```
<책폴더>/style/
  문체지침.md     ← 규칙. 맥락 **맨 앞**에 통째로 실린다(상한 4,000자)
  samples/        ← 기존 원고. 문체만 참고하도록 발췌(편당 1,200자·합 4,000자)
```

- 바인더에 **문체** 섹션으로 노출. 옛 책도 열기만 하면 폴더·씨앗이 생긴다(`ensureStyleRoom`)
- 씨앗의 `<!-- 안내 -->`와 `예)` 줄은 **AI에게 전달되지 않는다** — 안 고친 예시가 규칙처럼 굳는 것을 막는다
- 샌드위치: 맥락 맨 앞(지침) + 요청문 끝(`문체 지침을 그대로 지킬 것`) — 긴 맥락에서 앞부분이 흐려지는 것 보정
- 칩 `✍ 문체 지키는 중`으로 켜고 끈다. **문체 분석** 버튼이 `samples/`에서 지침 초안을 뽑아 준다

### 7.3 상호작용 형태

1. **채팅 패널** (우측): 프로젝트별 대화 히스토리 저장(`.ice/chats/`), 대화를 특정 챕터에 고정 가능
2. **인라인 액션**: 본문 텍스트 선택 → 플로팅 메뉴 (이어쓰기 / 퇴고 / 묘사 강화 / 대사 다듬기 / 요약)
   → 결과는 **diff 미리보기**로 제시 → 승인 시 적용(자동 스냅샷 후)
3. **프롬프트 프리셋**: 기본 제공(이어쓰기, 퇴고, 브레인스토밍, 설정 모순 검사, 챕터 요약, 캐릭터 인터뷰)
   + 사용자 정의 프리셋(변수 치환: `{{선택텍스트}}`, `{{현재챕터}}`, `{{캐릭터:이름}}`)

### 7.4 안전 원칙

- AI는 원고를 직접 수정하지 않는다 — 항상 제안 → diff → 승인
- 적용 전 자동 스냅샷 (§6.8)
- API 키는 OS 자격증명 저장소에만. 프로젝트 폴더(=클라우드 동기화 대상)에는 절대 저장 금지

### 7.5 폴더 전체 열람 — 목차 + 요청형 *(구현: `project.ts readForAi`, `shared/openRequest.ts`)*

장편 전체를 매 요청에 실을 수는 없다. 그래서 **서가 목록을 주고 청구기호로 책을 부르게** 한다.
사서(앱)만 서가에 들어가므로 경로 검증도 한곳에서 끝난다.

1. 맥락 끝에 **프로젝트 전체 목차** — 폴더 안 모든 문서·자료의 경로(✓는 이미 내용이 실린 것).
   앱이 못 읽는 형식(.hwp·.docx)도 **목록에는 넣는다** — 목록에 없으면 없는 파일이 되기 때문.
2. AI가 필요하면 답변 대신 `[[열람: 경로]]`만 출력한다(한 번에 5개).
3. 앱이 읽어 `[열람 결과]`로 붙여 **자동으로 다시 물어본다**. 최대 3왕복(무한 루프 차단).
4. 이미지도 같은 방식 — API 계열은 vision 첨부(base64는 생성 직전에 채운다), CLI 계열은
   **절대경로를 넘겨 직접 열게** 한다(`--add-dir`로 원고 폴더 읽기 권한 부여, 읽기 전용).

상한: 파일당 2만 자 · 합계 6만 자. 못 읽는 파일은 조용히 빠지지 않고 그 사실을 텍스트로 돌려준다
(AI가 "없는 파일을 봤다"고 착각하지 않게).

### 7.6 이미지 생성 — 비율은 앱이 책임진다 *(구현: `ai/image.ts`, `shared/imagePrompt.ts`)*

- 엔진: `agy` → `codex` → `gemini` 순 자동 감지. 성패는 종료코드가 아니라 **결과 파일**로 판정
- 비율 7종(1:1 · 3:2 · 2:3 · 4:3 · 3:4 · 16:9 · 9:16). 엔진이 못 맞추면 Electron `nativeImage`로
  **중앙 크롭**해 정확한 비율을 만든다(오차 2% 이내면 그대로 — 화질 손실 방지)
- 글자는 절대 그리지 않는다. 표지 제목은 앱이 내장 글꼴로 얹는다(재조판 자유 + 엉터리 글자 차단)

## 9. Windows → macOS 이식 전략

처음부터 지키면 이식 비용이 거의 0이 되는 규칙들:

1. **OS 분기 금지 존**: 렌더러 코드에는 플랫폼 분기 없음. 분기는 Main의 `platform/` 모듈에만 격리
2. **경로**: 항상 `path.join`/`path.sep`, 하드코딩 `\\` 금지. 프로젝트 내부 상대경로는 POSIX 통일
3. **단축키**: `CmdOrCtrl` 추상화만 사용
4. **메뉴**: macOS 네이티브 메뉴바 규약(App 메뉴, Window 메뉴) 대응 구조로 처음부터 정의
5. **시크릿**: safeStorage가 양쪽 OS 백엔드 자동 처리
6. **한글 IME**: Windows(한컴/MS IME)와 macOS 한글 입력기의 조합 이벤트 차이 — CM6 채택 이유.
   CI에 양 OS IME 스모크 테스트 시나리오 포함
7. **CI**: GitHub Actions에서 Win+Mac 동시 빌드를 M1(첫 마일스톤)부터 돌려서 이식 문제를 즉시 발견
8. 코드사이닝/공증(notarization)은 배포 단계(M6)에서 처리

**선례 활용**: ICEWriter가 이미 `build_mac.sh`로 macOS 빌드를 하고, `cli_text.py`의 `_augment_path()`에서
macOS GUI PATH 문제를 해결해 뒀다(§7.1a-8). ICEPDF는 electron-builder로 Win/Mac 양쪽을 패키징한다.
→ **ICEFiction은 두 앱의 빌드 스크립트·CI 설정을 출발점으로 복사**하면 이식 리스크가 크게 준다.

각 마일스톤은 "실행 증거"(빌드 성공, 테스트 통과, 시연 가능) 확인 후 완료 처리.

| 단계 | 범위 | 완료 기준 |
|---|---|---|
| **M0 설계 확정** | 이 문서 검토, §12 결정, 스캐폴드 | Win+Mac CI 빌드 통과하는 빈 앱 |
| **M1 에디터 코어** | 프로젝트 열기/생성, 바인더 트리, CM6 에디터, 자동저장, 글자수/원고지, **폴더 열기·탐색기 연동, 드래그드롭 자료 반입(복사)** | 실제 집필 + 이미지 끌어넣기 동작. 폴더 복사만으로 다른 PC에서 열림 |
| **M2 설정·자료** | 캐릭터·세계관 모듈, 프론트매터 인스펙터, 위키링크+백링크, 검색(FTS), **자료 패널·썸네일·라이트박스·인라인 미디어 프리뷰·동영상 재생** | 캐릭터에 얼굴 레퍼런스 붙이고 씬에서 곁눈질 |
| **M3 AI 어시스턴트** | 프로바이더 3계열, 채팅 패널, 컨텍스트 칩, 인라인 액션+diff 적용, 프리셋 | Ollama·Claude API·`claude -p` 3종 실동작 |
| **M4 내보내기** | TXT/MD/DOCX/EPUB 컴파일, 프리셋 | 30챕터 프로젝트 → 4포맷 정상 출력 |
| **M5 안전망·이식성** | 스냅샷+diff, 휴지통, 대시보드, 집중 모드, 찾기·바꾸기, **`.icefic` 번들 입출력, 경로 검증, 누락 자료 감지, 기존 원고 임포트** | AI 편집 롤백 + 다른 PC로 번들 이동 왕복 시연 |
| **M6 배포** | 설치본, 자동 업데이트, macOS 서명·공증, 온보딩·샘플 프로젝트 | 양 OS 설치본 배포 |

MVP = M1~M3. 여기까지가 "쓸 만한 물건"의 기준.
**이식성 참고**: "폴더 복사·클라우드 동기화로 이동"은 M1부터 공짜로 된다(폴더 기반이라 내재적).
`.icefic` 번들·누락 자료 감지·기존 원고 임포트 같은 **다듬은 이식 도구**가 M5에 온다. 단, "모든 참조는
상대·POSIX 경로"(§4·§6.11) 규율은 **M1부터 강제**해야 나중에 깨지지 않는다.
