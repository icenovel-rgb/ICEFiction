# ICEFiction 디자인 시스템 (배색·토큰)

> 색은 컴포넌트에 **직접 쓰지 않는다**. 아래 CSS 변수(토큰)만 쓴다. 라이트/다크는 토큰 값만 바꾼다.
> 이 규칙을 어겨서 "라이트에서 흰 글자가 안 보이는" 버그가 났었다(§변경이력). 하드코딩 금지.

## 0. 두 겹(Two-layer) 모델

- **앱 크롬**(도구창: 바인더·패널·상단바·다이얼로그) = `--bg/--panel/--text/--accent…` 토큰.
  `settings.appMode`(라이트/다크)가 `html[data-app-mode]`로 이 토큰을 통째로 바꾼다.
- **원고 종이**(에디터 본문) = `--paper-*` 토큰. `settings.theme`(세피아/다크/화이트/커스텀)가 바꾼다.
  크롬과 **독립** — 라이트 앱 + 세피아 종이 조합도 정상.

## 1. 토큰 (chrome)

| 토큰 | 다크(기본) | 라이트 | 용도 |
|---|---|---|---|
| `--bg` | `#2b2b2b` | `#f3f4f6` | 본문/앱 배경 |
| `--sidebar` | `#252526` | `#e9ebef` | 바인더 |
| `--toolbar` | `#2a2b2e` | `#e6e8ec` | 상단바·상태바 |
| `--panel` | `#2d2d30` | `#f7f8fa` | 모달·카드·패널 |
| `--text` | `#e8e8e8` | `#1f2328` | 본문 글자 |
| `--muted` | `#9498a0` | `#5b616b` | 보조 글자 |
| `--border` | `#3c3e44` | `#d3d7dd` | 테두리 |

| `--input-bg` | `#1e1e1e` | `#fff` | 입력창 |

## 2. 정체색 (accent, 두 모드 공통)

- `--accent` `#5b52d6` — 채움(강조 버튼·선택 챕터). **흰 글자 대비 5.7:1(AA 통과)**.
- `--accent-hi` `#857df0` — 테두리·하이라이트·링크. 다크 배경에서 묻히지 않는 밝은 인디고.
- `--accent-soft` `rgba(122,114,240,.34)`(다크) / `.16`(라이트) — 선택 영역·칩 배경.
- 남색/인디고는 아이콘 F 배지 정체색(BLUEPRINT §0.3). 밝은 배경에 **글자로** 쓸 땐 `#4038a8`.

### 규칙 — 강조 버튼
`background: var(--accent); color: #fff;` **명시적으로** 쓴다(예: `.lib-new`, `.ai-save`, `.dialog-confirm`).
그러면 라이트 모드가 `--btn-bg`만 바꿔도 강조 버튼은 안 깨진다. 절대 `button {}`를 통째로 덮지 말 것
(특이도로 강조 버튼까지 덮여 흰 글자+밝은 배경 = 안 보임).

## 3. 원고 종이 (paper) + 마크다운

- `--paper-bg/--paper-text/--paper-font/--paper-fontsize/--paper-lineheight` — settings가 주입.
- 마크다운 색은 **종이 밝기**에 맞춘다: `applySettings`가 배경 명도로 `html[data-paper-dark]` 판정.
  - `--md-link` 밝은 종이 `#5b54d6` / 어두운 종이 `#b3acff`
  - `--md-muted` = `color-mix(--paper-text 55%, transparent)` (종이색 상대 — 항상 보임)
  - `--md-code-bg` = 종이색 12~18% 틴트

## 4. 시맨틱

- `--dirty` `#e0a83b`(다크)/`#a9761a`(라이트) — 미저장(앰버).
- `--danger` `#b62324` — 삭제/위험.
- 상태 배지: 초고=회색 `#6b7280`, 퇴고중=`--dirty`, 완료=녹색 `#2f855a`.

## 5. 대비 기준

- 본문 글자: **AA 4.5:1** 이상. 보조/큰 글자: 3:1 이상.
- 밝은 배경 위 흰 글자, 어두운 배경 위 어두운 글자 = 금지. 새 색을 넣기 전 대비를 계산하거나 토큰을 쓴다.
